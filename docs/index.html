Where your data goes

Your chats stay in your browser.

1 · Browser

Parse

The WhatsApp .txt files are read and split into messages on your device.

2 · Browser

Store

Chats and results live in IndexedDB. No database holds your messages.

3 · Gemini API

Analyse

Each weekly segment goes from your browser to Gemini for a structured read.

4 · Browser

Delete

Open /api/clear-all-data to wipe IndexedDB and local storage.

Two honest caveats. The text you analyse is sent to Google's Gemini API. And the server passes your Gemini key to the browser through /api/token/generate, so run Cognition locally or keep it behind its password gate. The Ad Tracker works differently: it reads Meta, Stripe and Postgres from the server.

Quick start

Running in about two minutes.

  1. Get a Gemini API key from Google AI Studio. You also need Node.js 20 or newer.
  2. Set two variables in .env.local: GEMINI_API_KEY and APP_PASSWORD. Everything else is optional.
  3. Sign in at /login with your password, then open /onboarding.
  4. Drop in your exports. In WhatsApp: open the chat, Export chat, Without media.
# clone and run
$ git clone \
  https://github.com/harrythentrepreneur/cognition-insights.git
$ cd cognition-insights
$ npm install
$ cp .env.example .env.local
# then set GEMINI_API_KEY
# and APP_PASSWORD in .env.local
$ npm run dev
# open http://localhost:3000
