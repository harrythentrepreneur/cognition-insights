# Onboarding Components\n\nRefactored and cleaned-up onboarding flow components with shared utilities and consistent patterns.\n\n## Structure\n\n```\nsrc/components/onboarding/\n├── shared/                    # Shared utilities and constants\n│   ├── index.ts              # Re-exports all shared utilities\n│   ├── types.ts              # TypeScript interfaces and types\n│   ├── styles.ts             # Common styles, colors, and constants\n│   └── animations.ts         # Animation utilities and keyframes\n├── OnboardingFlow.tsx        # Main flow coordinator\n├── Step1Welcome.tsx          # Welcome step\n├── Step2Journey.tsx          # Journey selection step  \n├── Step4UploadFiles.tsx      # File upload step\n├── Step5Processing.tsx       # Processing/analysis step\n├── Step6Results.tsx          # Results and navigation step\n└── README.md                 # This file\n```\n\n## Key Improvements\n\n### 🧹 **Code Cleanup**\n- Removed duplicate `ResultsStep.tsx` file\n- Extracted common styles into shared constants\n- Standardized TypeScript interfaces\n- Eliminated repetitive inline styles\n\n### 🎨 **Shared Style System**\n- **Colors**: Centralized color palette in `COLORS` constant\n- **Fonts**: Shared font loading utilities with Satoshi and Inter\n- **Spacing**: Consistent spacing system via `SPACING` constant\n- **Animations**: Reusable animation utilities and timing functions\n\n### 🔧 **Type Safety**\n- Consistent prop interfaces across all components\n- Shared types for onboarding flow state\n- Centralized animation state management\n\n### ⚡ **Performance**\n- Reduced bundle size by eliminating duplicate code\n- Optimized font loading with shared utilities\n- Consistent animation performance\n\n## Usage\n\n### Importing Shared Utilities\n\n```typescript\n// Import everything\nimport { \n  COLORS, \n  SPACING, \n  buttonStyle, \n  createFadeInUpStyle,\n  ProcessingStepProps \n} from './shared';\n\n// Or import specific modules\nimport { COLORS } from './shared/styles';\nimport { createFadeInUpStyle } from './shared/animations';\nimport { ProcessingStepProps } from './shared/types';\n```\n\n### Component Props\n\nAll components now use standardized prop interfaces:\n\n```typescript\n// Example component props\ninterface WelcomeStepProps {\n  sessionId?: string;\n  onContinue?: () => void;\n}\n```\n\n### Styling\n\nUse shared style constants for consistency:\n\n```typescript\nconst myStyle = {\n  color: COLORS.PRIMARY_TEXT,\n  padding: SPACING.PAGE_PADDING,\n  ...buttonStyle\n};\n```\n\n### Animations\n\nUse animation utilities for consistent motion:\n\n```typescript\nconst animatedElement = {\n  ...createFadeInUpStyle(0.2), // 0.2s delay\n  ...createLoadedElementStyle(isLoaded)\n};\n```\n\n## Component Flow\n\n1. **OnboardingFlow** - Manages state and navigation between steps\n2. **Step1Welcome** - Landing page with welcome message\n3. **Step2Journey** - Journey/analysis type selection\n4. **Step4UploadFiles** - File upload interface\n5. **Step5Processing** - Analysis progress with animations\n6. **Step6Results** - Results display with navigation options\n\n## Shared Constants\n\n### Follow the established naming convention (`Step[N][Name].tsx`)\n5. Update `OnboardingFlow.tsx` to include the new step\n\n## Breaking Changes\n\n- `ResultsStep.tsx` removed (use `Step6Results.tsx`)\n- All components now require proper TypeScript interfaces\n- Inline styles replaced with shared constants where applicable\n\nThis refactoring maintains **100% functional compatibility** while significantly improving code maintainability and consistency.
